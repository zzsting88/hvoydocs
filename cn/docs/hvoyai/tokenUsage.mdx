## 抽奖 Token 用在 Codex

如果您的 Token 是从 [hvoy 免费抽奖](https://www.hvoyai.com/free-tokens/lottery)得到的，一般可以直接给 Codex 使用。

### 找到 API URL 和 API Key

1. 打开 [免费抽奖](https://www.hvoyai.com/free-tokens/lottery)，登录后点击 **我的记录**。
2. 打开 [我的抽奖记录](https://www.hvoyai.com/free-tokens/lottery/mine)，查看中奖次数和中奖记录。
3. 点击某一次中奖记录的 **查看详情**，例如 `https://www.hvoyai.com/free-tokens/lottery/mine/2026-06-11-1400` 这种详情页。
4. 在详情页复制 **API URL** 和 **API Key**。

中奖详情页属于个人页面，会显示您的真实 API Key。本文档不放真实页面截图，避免误把 Key 泄露出去。

![我的抽奖记录示意](/assets/images/token-usage/zhongjiangjilu.jpg)

![中奖详情复制 API 信息示意](/assets/images/token-usage/zhongjiang.jpg)



## 测试 API Key 是否可用
www.hvoyai.com 会每 5 分钟检查一次 API Key 是否可用，所以一般情况下，这些 API Key 都是可以使用的。

如果您觉得 API Key 不可用，可以用[这个页面](https://www.hvoyai.com/api-key-tester)来进行测试。

## 免费 API Key 用 CCSwitch 接入

如果您的 Token 来自 [免费 API Key](https://www.hvoyai.com/free-tokens/api-keys)栏目，一般建议先用 CCSwitch 管理，再由 CCSwitch 接入 Codex 或 Claude Code。

在这个页面里，每一行都会显示 API URL、API Key、模型和领取按钮。先领取，再复制 API URL 和 API Key。

![hvoy 免费 API Key 列表](/assets/images/token-usage/hvoy-api-keys-annotated.png)

CCSwitch 是一个本地桌面工具，可以统一管理 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw、Hermes 等工具的供应商配置、切换和本地路由。官方文档见 [CCSwitch 快速开始](https://www.ccswitch.io/zh/docs?section=getting-started&item=quickstart)，下载见 [GitHub Releases](https://github.com/farion1231/cc-switch/releases)。

![CCSwitch 主界面](/assets/images/token-usage/ccswitch-main-annotated.png)

### 安装 CCSwitch

打开 [CCSwitch Releases](https://github.com/farion1231/cc-switch/releases)，按系统下载：

![CCSwitch 下载页面](/assets/images/token-usage/ccswitch-releases-annotated.png)

| 系统 | 推荐文件 |
| --- | --- |
| macOS | `.dmg` |
| Windows | `.msi` |
| Linux | `.deb`、`.rpm` 或 `.AppImage` |

macOS 也可以用 Homebrew:

```bash
brew install --cask cc-switch
```

### 添加 hvoy 免费 API Key

1. 打开 [免费 API Key](https://www.hvoyai.com/free-tokens/api-keys)，复制页面给出的 API URL 和 API Key。
2. 打开 CCSwitch。
3. 选择要接入的应用，例如 **Codex** 或 **Claude Code**。
4. 点击右上角的 `+` 添加供应商。
5. 如果列表里有对应供应商预设，优先选择预设；没有就选择自定义供应商。
6. 填入 API URL、API Key 和模型名。
7. 点击添加，然后在供应商卡片上点击启用。

![CCSwitch 添加供应商入口](/assets/images/token-usage/ccswitch-add-annotated.png)

![CCSwitch 关键字段填写示意](/assets/images/token-usage/ccswitch-fields-demo.png)

Codex 切换供应商后通常需要重启终端或重新打开 Codex。Claude Code 在 CCSwitch 文档中说明为支持热切换，但如果您遇到不生效，也建议先关闭再重新打开。

### Codex 需要本地路由时

有些免费 API Key 背后的服务只支持 OpenAI Chat Completions 协议，而 Codex 更依赖 Responses 协议。遇到这种情况，需要让 CCSwitch 开启本地路由映射。

在 CCSwitch 的 Codex 供应商里：

1. 打开或确认 **需要本地路由映射**。
2. 确认模型映射表里有可用模型。
3. 启动 CCSwitch 的本地代理/本地路由服务。
4. 启用 Codex 接管。
5. 重启 Codex。

CCSwitch 官方文档对这部分有更完整说明:

- [添加供应商](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/2-providers/2.1-add.md)
- [切换供应商](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/2-providers/2.2-switch.md)
- [代理服务](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/4-proxy/4.1-service.md)


### 写入 Codex 配置

如果您不用 CCSwitch，可以直接把抽奖页给出的 API URL 和 API Key 写入 Codex 配置。

![Codex 配置字段示意](/assets/images/token-usage/codex-config-demo.png)

`~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "这里粘贴您的 API Key"
}
```

`~/.codex/config.toml`:

```toml
model_provider = "hvoy"
model = "页面或供应商说明里的模型名"
model_reasoning_effort = "high"
disable_response_storage = true

[model_providers.hvoy]
name = "hvoy"
base_url = "这里粘贴页面显示的 API URL"
wire_api = "responses"
requires_openai_auth = true
```

保存后关闭当前 Codex 和终端，重新打开终端再运行：

```bash
codex
```

进入 Codex 后可以先问一句简单问题测试：

```text
您好，请用一句话说明您现在是否可以正常工作
```

<Warning>
API URL 以中奖详情页显示为准。不要随意删掉或追加 `/v1`、`/responses` 等路径，除非页面明确要求。
</Warning>

## 小米 MiMo Token

如果您的免费 Token 是小米 MiMo 的分享 Token，不要直接套用普通 OpenAI 或 Anthropic 配置。请优先看小米官方工具接入文档：

![小米 MiMo 工具接入页面](/assets/images/token-usage/xiaomi-tools-annotated.png)

- [小米 MiMo 工具接入总览](https://platform.xiaomimimo.com/docs/zh-CN/integration/tools-overview)
- [小米 MiMo 静态文档：Overview of AI Tools](https://platform.xiaomimimo.com/static/docs/integration/tools-overview.md)
- [小米 MiMo Claude Code 配置](https://platform.xiaomimimo.com/static/docs/integration/claudecode.md)

如果您通过 CCSwitch 使用小米 MiMo，可以在 CCSwitch 里选择 **Xiaomi MiMo** 或 **MiMo Token Plan** 相关预设；预设列表以您安装的 CCSwitch 版本为准。

## 常见问题

### 找不到 API URL

先确认 Token 来源：

- 抽奖 Token：到 [我的抽奖记录](https://www.hvoyai.com/free-tokens/lottery/mine)里点进中奖详情页。
- 免费 API Key：到 [免费 API Key](https://www.hvoyai.com/free-tokens/api-keys)页面查看。
- 小米 MiMo：到小米平台控制台或小米官方工具接入文档查看。

### Codex 还是走旧的供应商

Codex 通常在启动时读取配置。切换供应商或修改 `~/.codex/config.toml` 后，关闭 Codex 和终端，重新打开再试。

### 返回 401 或 403

常见原因：

- API Key 没有复制完整。
- API URL 填错或多加了路径。
- Token 已过期、额度用完或未中奖。
- CCSwitch 里启用了错误的供应商卡片。

### 返回 model not found

检查模型名是否是供应商支持的模型。使用 CCSwitch 时，可以先点 **获取模型** 或按供应商文档填写模型名。

### 要不要把抽奖 Token 也放进 CCSwitch

可以。如果您希望统一管理多个 Codex/Claude Code 供应商，抽奖 Token 也可以作为 Codex 自定义供应商添加到 CCSwitch。只是抽奖 Token 本身通常可以直接给 Codex 用，不一定必须经过 CCSwitch。
