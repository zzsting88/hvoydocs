CPM 是按千次有效展示计费的广告投放方式。你先给 Partner 钱包充值，再创建 CPM 计划并选择投放覆盖。系统会在用户访问首页或榜单页时判断哪些广告可以展示，按 CPM 出价参与排序，并且只对通过可见性和平台质量保障的展示扣费。

这里的展示不是页面打开次数，也不是广告被分配到页面的次数。普通赞助位需要在用户当前可见区域内至少 50% 可见，并且连续停留满 1 秒，才会进入有效展示口径。点击不会产生额外 CPM 扣费。

## 阅读路径

- 第一次投放：先看 [快速上手](#快速上手) 和 [使用流程](#使用流程)。
- 想理解计费：看 [展示逻辑](#展示逻辑)、[什么是有效展示](#什么是有效展示) 和 [怎么扣费](#怎么扣费)。

- 只想确认一个问题：直接看 [常见问题](#常见问题)。

## 快速上手

第一次使用 CPM 投放时，可以按下面顺序完成：

1. 确认账号下已有站点，并且要投放的站点处于 Partner Pro 有效期内。
2. 检查站点展示资料和落地页是否可用。
3. 进入 `Partner 后台 -> 钱包` 完成充值，确认钱包有可用余额。
4. 进入 `广告投放 -> 创建计划`，选择投放站点和投放覆盖。
5. 为每个投放覆盖设置 CPM 出价，出价不能低于页面显示的当前底价。
6. 按需要设置总预算、每日预算、投放日期、每日时段和落地页追踪设置。
7. 创建后先使用预览链接检查展示效果；预览不会产生真实扣费。测试计划只通过预览链接展示，不进入真实流量。
8. 正式投放后，在投放概览和计划详情中查看展示机会、有效展示、计费展示、点击和花费。

如果页面提示站点未开通 CPM 投放资格、钱包余额不足、Partner Pro 已失效或出价低于底价，需要先处理对应问题，再继续投放。

## 使用流程

### 1. 准备账号和钱包

使用 CPM 前需要满足这些条件：

- 已登录 Partner 后台，并且账号下已有站点。
- 要投放的站点处于 Partner Pro 有效期内。
- 站点展示资料和落地页可用。
- Partner 钱包有可用余额。
- 站点已开通 CPM 投放资格；未开通时页面会提示提交工单。

进入 `Partner 后台 -> 钱包` 可以查看钱包余额、可用余额、CPM 钱包占用、累计支出、充值订单和钱包流水。

![钱包页面](/assets/images/cpm/wallet.png)

几个数字的含义：

- 钱包余额：当前 Partner 钱包总余额，Partner Pro 和 CPM 共用。
- 可用余额：可继续用于支付或投放的金额。
- CPM 钱包占用：已经产生展示、正在等待确认扣费的金额。计划总预算不会在创建时一次性锁定。
- 钱包流水：记录充值、Partner Pro 支付、CPM 扣费、退款、补偿返还和管理员调账。

充值时填写金额，勾选协议，然后点击 `前往 Stripe 充值`。支付完成后回到页面，必要时点击 `我已完成充值` 同步到账状态。

### 2. 创建 CPM 计划

进入 `Partner 后台 -> 广告投放 -> 创建计划`。

![创建 CPM 计划](/assets/images/cpm/create-campaign.png)

创建页按步骤填写：

- 广告计划名称：只用于你在后台识别计划；不填写时系统会生成默认名称。
- 投放站点：选择要推广的站点。
- 投放覆盖：选择广告要覆盖的页面、模型分组和投放区域。当前主要开放 `搜索顶部`，排序维度默认覆盖该模型分组下的全部排序方式。
- CPM 出价：每个投放覆盖都有自己的 CPM 出价，不能低于该覆盖当前底价。页面会显示底价和推荐价格。
- 总预算：计划最多可消耗的金额上限；不填写代表不单独限制总预算，不会在创建时一次性扣除。
- 每日预算：单个自然日最多消耗多少；不填写代表不单独限制每日预算。
- 投放日期：可以长期有效，也可以设置开始和结束时间。
- 每日时段：可选；开启后只在指定时段投放。
- 落地页追踪设置：只允许追加简单追踪标记，例如 `aff=1233`。系统不会允许修改站点域名或原始落地页路径。
- 测试计划：只通过预览链接展示，不进入真实流量，也不会产生真实扣费。

一个计划可以有多个投放覆盖。每个启用覆盖只参与自己对应的展示机会，并使用该覆盖自己的 CPM 出价；关闭或删除覆盖后，不再争取新的展示机会，历史展示、点击和消费记录仍会保留。

### 3. 查看投放概览

进入 `广告投放 -> 投放概览`。这里汇总当前账号下 CPM 计划的状态、预算、有效展示、点击和花费。

![投放概览](/assets/images/cpm/partner-overview.png)

概览里的预算消耗按“已确认花费 + 待确认扣费”理解。总预算只是上限，不是创建计划时的预扣款。

### 4. 管理计划

进入 `广告投放 -> 计划管理`。

![计划管理](/assets/images/cpm/campaigns.png)

你可以执行这些操作：

- 详情：查看投放漏斗、趋势、覆盖拆分、成交价分布和操作历史。
- 预览：生成预览链接，检查广告展示效果；预览不扣费。
- 编辑投放：调整预算、时间、长期有效、每日时段和落地页追踪设置。
- 新增投放覆盖：给计划增加新的页面、模型或投放区域覆盖。
- 启用 / 停用 / 删除覆盖：控制单个覆盖是否继续参拍。
- 调整 CPM 出价：单独调整某个覆盖的出价，新出价不能低于当前底价。
- 调整预算：修改总预算和每日预算。
- 投放 / 暂停 / 归档：控制计划状态。
- 复制：复制为一个新的草稿计划。

常见状态包括草稿、排期、投放中、用户暂停、管理员暂停、钱包余额不足、Partner Pro 失效、已耗尽、已结束和已归档。

### 5. 查看计划详情

计划详情页用于看清楚一次投放到底发生了什么。

![计划详情](/assets/images/cpm/campaign-detail.png)

核心区域：

- 投放漏斗：获得展示机会、用户看到广告、确认扣费展示、点击、花费。
- 趋势：按天查看可见展示、计费展示和点击走势。
- 投放覆盖：按覆盖查看展示、点击、花费、启用状态和出价。
- 成交价分布：查看匿名成交价区间，用于判断出价空间；不会暴露竞争对手。
- 曝光分析：提示低曝光原因，例如预算不足、钱包不足、出价竞争力低、时段未到、频控达到、站点未探测该模型等。
- 操作历史：记录创建、启停、改价、预算调整、覆盖变更等动作。
- 展示明细：查看单条展示的结算与诊断状态。

### 6. 优化投放

计划开始投放后，可以结合计划详情里的投放漏斗、趋势、投放覆盖、成交价分布、曝光分析和展示明细判断下一步动作：

- 获得展示机会较少：先检查计划状态、覆盖状态、Partner Pro、钱包余额、预算、投放日期、每日时段和 CPM 出价。曝光分析中也会提示预算不足、钱包不足、出价竞争力低、时段未到、频控达到、站点未探测该模型等低曝光原因。
- 获得展示机会正常，但有效展示较少：说明广告已经赢得展示位置，但达到可见标准的展示较少。可以结合趋势中的可见展示、计费展示和可见率继续观察。
- 有效展示正常，但点击较少：点击不会产生额外 CPM 扣费，可以结合点击、vCTR、站点展示资料和落地页可用性判断展示效果。
- 花费接近预算上限：可在后台调整总预算、每日预算、投放时段，或暂停不需要继续投放的覆盖。
- 出价竞争力不足：可以参考页面推荐价格、当前底价和匿名成交价分布，调整对应覆盖的 CPM 出价。新出价不能低于当前底价。

修改出价、预算、时间、每日时段或覆盖后，只影响之后新的展示机会。历史展示按发生时的成交价结算，不会因为后续调整反向重算。

## 展示逻辑

### 什么是投放覆盖

投放覆盖是 CPM 计划真正参与展示机会的单位。一个覆盖通常对应一个页面、一个模型分组和一个投放区域，例如“榜单页 / GPT-5.5 / 搜索顶部”。

当前 Partner 侧主要开放搜索顶部投放区域。你在创建计划时可以选择多个覆盖，并为每个覆盖设置自己的 CPM 出价。系统会按覆盖分别参拍、分别统计展示和花费。

### 哪些广告可以进入候选

每次页面出现可投放位置时，系统会先做准入判断。只有同时满足这些条件的覆盖才会进入候选池：

- 计划状态允许投放，覆盖处于启用状态。
- 站点和 Partner 账号处于正常状态。
- 站点 Partner Pro 有效。
- 钱包可用余额足够完成本次展示预留。
- 总预算和每日预算没有达到上限。
- 当前时间在投放日期和每日时段内。
- CPM 出价大于 0，并且不低于该覆盖底价。
- 站点资料和落地页配置可用于展示。
- 符合平台投放质量要求。

被排除的原因会用于诊断，但普通用户不会看到广告主钱包、竞争对手出价或平台质量保障细节。

### 排名和成交价

真实流量只使用手动 CPM 出价，不支持自动出价、oCPM、Nobid、CPC 或 CPA。

同一个投放区域内，候选按 CPM 出价从高到低排序；出价相同则先看创建时间，仍相同再按计划 ID 排序，保证结果可解释、可复现。

成交价采用广义第二价格逻辑：

```text
实际 CPM = min(你的出价, max(覆盖底价, 下一个不同站点有效出价 + ¥0.01))
```

例子：

- 你的出价是 ¥100 CPM，第二个不同站点出价是 ¥80 CPM，底价是 ¥75 CPM，则实际 CPM 是 ¥80.01。
- 你的出价是 ¥100 CPM，第二名低于底价，底价是 ¥75 CPM，则实际 CPM 是 ¥75。
- 只有你一个有效候选时，实际 CPM 按底价确认。
- 实际 CPM 不会超过你的出价。

同一个站点在同一次页面展示里最多出现一次。同一站点有多条有效覆盖或计划时，只用该站点最高的有效出价代表该站点参与排序；同站点其他出价不会抬高自己的成交价。系统也会避免同一主体在同一页面里过度重复展示。

如果没有任何合格候选，页面不展示赞助位，也不会扣费。

## 什么是有效展示

系统把一次广告从返回到扣费分成几层：

| 层级 | 含义 | 是否扣费 |
|---|---|---|
| 获得展示机会 | 系统选择了你的广告，并准备在页面中展示 | 否 |
| 用户看到广告 | 广告达到可见标准 | 进入计费候选 |
| 确认扣费展示 | 展示通过预算、质量和结算确认 | 是 |
| 已扣费 | 结算任务写入钱包流水 | 已扣 |
| 无效展示 | 结算前或结算后被判定无效 | 不扣或退回 |

普通图文赞助位的有效展示标准：

- 广告元素至少 50% 在用户可见区域内。
- 连续可见时间达到 1000ms。
- 展示必须发生在真实、可确认的用户浏览场景中。
- 无法可靠确认可见性的展示，只记录展示机会，不进入扣费。

预览广告、测试计划、自然推荐位展示、自然推荐位点击，都不会触发 CPM 扣费。

## 怎么扣费

扣费以确认扣费展示为准，不按点击扣费。

单次展示的理论费用是：

```text
单次展示费用 = 实际 CPM / 1000
```

如果实际 CPM 是 ¥75：

- 1000 次确认扣费展示，总费用是 ¥75。
- 1 次确认扣费展示，对应 ¥0.075，会进入结算批次聚合。
- 不足 1 分的金额会合并到结算批次里统一处理，不会直接丢弃。

预算和钱包处理顺序：

1. 页面出现展示机会时，系统先检查计划状态、预算、钱包余额和投放质量。
2. 通过检查后，广告才有机会展示给用户。
3. 用户真正看到广告后，这次展示会进入待确认扣费。
4. 展示确认有效后，从钱包扣款并写入钱包流水。
5. 无效展示不会扣费；如果扣费后发现展示无效，会通过钱包返还或补偿返还修正。

历史展示按发生时的成交价结算。之后改出价、改底价或暂停计划，都不会反向重算已经合法发生的展示。暂停前已经合法发生并通过确认的展示仍可结算。

全系统的日预算、报表自然日和结算归属按统一自然日口径计算。

## 预算和投放质量保护

Hvoy 会把预算保护放在投放链路的核心位置。平台会在投放、展示和结算环节持续保障质量，尽量让预算花在真实、可见、有价值的展示上。

平台会提供这些保护：

- 控制同一广告的重复触达，避免过度展示影响用户体验。
- 在预算不足、钱包余额不足、投放时段未到或计划状态不允许时，自动停止争取新的展示机会。
- 对无法稳定确认质量的展示采取保守处理，优先保护广告主预算。
- 报表会区分展示机会、有效展示和计费展示，方便广告主判断预算是否真正花在有效曝光上。

## 防攻击和无效流量处理

CPM 最重要的是让广告主为真实曝光付费，而不是为无效流量买单。Hvoy 建立了覆盖投放、展示、结算和复核的多层质量保障体系，用来保护广告主预算和平台生态。

我们会重点保障这些结果：

- 只有真实可见、符合平台质量标准的展示才会进入扣费口径。
- 同一次展示不会被重复计费。
- 不符合质量要求的展示不会轻易进入最终结算。
- 如果结算后发现展示不符合质量要求，会通过钱包返还或补偿返还修正。
- 平台会持续升级质量保障能力，降低无效消耗预算的风险。

这些能力的目标是让 CPM 预算更可控、结算更可信、报表更接近真实投放效果。为了保护广告主和平台生态，Hvoy 不公开具体防护机制，以免影响防护效果。

## 报表口径

计划详情中的常见指标：

- 获得展示机会：广告赢得展示位置的次数，不直接扣费。
- 有效展示 / 用户看到广告：满足可见性标准的展示。
- 计费展示 / 确认扣费展示：通过确认并产生扣费的展示。
- 点击：用户从广告位点击进入落地页的次数。
- vCTR：点击数 / 有效展示数。
- 可见率：有效展示 / 获得展示机会。
- 平均 CPM：区间花费 / 计费展示数 × 1000。
- 花费：已确认扣费金额。
- 退款金额：已从扣费中退回的钱包金额。

广告主报表只展示自己的投放数据、匿名成交价分布和质量诊断提示。竞争对手身份、对手具体出价、钱包余额和平台质量保障细节不会暴露给 Partner 用户。

## 低曝光排查

如果计划已经创建，但展示很少或没有展示，可以按下面顺序排查：

| 排查项 | 可能原因 | 处理方式 |
|---|---|---|
| 计划状态 | 计划仍是草稿、排期、暂停、已耗尽、已结束或已归档 | 在计划管理中检查状态，确认计划允许投放 |
| 覆盖状态 | 对应覆盖已关闭或删除 | 启用覆盖，或新增正确的页面、模型分组和投放区域 |
| Partner Pro | 站点 Partner Pro 已失效 | 恢复 Partner Pro 后再继续投放 |
| 钱包余额 | 钱包可用余额不足 | 充值并等待余额同步 |
| 预算 | 总预算或每日预算达到上限 | 调整预算，或等待新的自然日预算口径 |
| 投放时间 | 当前不在投放日期或每日时段内 | 检查投放日期和每日时段设置 |
| CPM 出价 | 出价低于当前底价，或竞争力不足 | 将出价调整到不低于当前底价，并结合推荐价格和成交价分布判断 |
| 站点配置 | 站点资料或落地页不可用于展示 | 检查站点展示资料、落地页和追踪参数 |
| 平台质量保障 | 展示不符合平台投放质量要求 | 查看曝光分析和展示明细中的诊断信息 |

低曝光不一定代表系统异常。展示机会、有效展示和计费展示会受到计划状态、覆盖状态、预算、钱包、时段、出价、站点配置和平台质量保障共同影响。

## 常见问题

### CPM 出价是不是最终一定支付的价格？

不是。CPM 出价是你愿意为 1000 次确认扣费展示支付的最高价格。实际 CPM 通常由覆盖底价和下一个不同站点有效出价决定，并且不会超过你的出价。

### 为什么获得展示机会、有效展示和计费展示不一样？

获得展示机会表示广告赢得了页面位置；有效展示表示用户真的看到了广告；计费展示表示这次展示通过预算和质量确认，并进入确认扣费。系统只按计费展示扣费。

### 点击会不会额外收费？

不会。CPM 按确认扣费展示收费，点击只用于衡量效果。

### 为什么计划显示钱包余额不足？

钱包可用余额不足以继续为新展示做预留。充值后，符合条件的计划和覆盖可以恢复投放。

### 为什么有待确认扣费？

广告赢得机会并产生可见展示后，金额会先进入待确认占用。结算任务确认有效后才扣款；无效展示会释放占用。

### 测试计划会不会产生真实花费？

不会。测试计划只用于预览，不进入真实竞价流量，也不会产生真实扣费。

### 为什么有退款或补偿返还？

系统会持续复核展示质量。如果结算后发现展示不符合计费要求，会通过钱包流水返还，通常显示为退款或补偿返还。

### 修改预算或出价后，会不会影响已经发生的展示？

不会反向重算。历史展示按发生时的成交价结算。之后改出价、改底价或暂停计划，都只影响后续新的展示机会。

### 计划暂停后还会继续扣费吗？

暂停后不会继续争取新的展示机会。暂停前已经合法发生并通过确认的展示，仍可按原规则结算。

### 总预算和每日预算有什么区别？

总预算是计划最多可消耗的金额上限；每日预算是单个自然日最多可消耗的金额上限。预算设置是投放消耗上限，不代表创建计划时一次性预扣；实际消耗按确认扣费展示结算。

### 为什么报表里的花费和钱包流水可能不是同时变化？

展示会先进入待确认扣费，确认有效后才从钱包扣款并写入钱包流水。因此短时间内可能会看到待确认扣费、已确认花费和钱包流水存在时间差。
