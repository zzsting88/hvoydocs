hvoy 排行榜页面:

https://www.hvoy.ai/leaderboard?tab=opus47


排行榜按模型维度展示 API 中转站的可用分组。页面上会展示站点、站点分组、价格、价格趋势、在线率、掺水率、延迟、运行状态等信息，方便用户快速比较不同站点在同一个模型上的表现。

默认的「精选」排序不是按单一指标排序，也不是简单地价格越低越靠前。hvoy 会根据自动探测、价格抓取、用户行为和站点认证等信号，给每个「站点 + 分组 + 模型」组合计算综合推荐分，然后动态生成榜单顺序。

## 主要排序因素

### 1. 站点和分组稳定度

稳定度是排序中最重要的因素之一。hvoy 会持续测试站点在对应模型和分组下的可用性，包括最近一段时间的在线率、连续成功情况、失败频率、异常波动和运行状态。

如果一个分组长期稳定、失败少、运行状态连续健康，会获得更高排序权重。反之，即使价格较低，只要最近失败较多或状态波动明显，排序也可能下降。

### 2. 最近价格和价格变动

排行榜会参考该分组最近抓取到的价格，以及最近一段时间的价格趋势。

价格较低通常对用户更有吸引力，但 hvoy 不会只按最低价排序。系统会同时考虑价格是否稳定、是否突然大幅变化、价格信息是否可信、是否存在过低但质量不稳定的情况。


### 3. hvoy 系统质量打分

hvoy 会对每个分组维护内部质量打分。这个分数会综合接口可用性、返回质量、异常情况、是否疑似掺水、模型匹配情况、探测数据一致性等因素。

质量打分较高的分组会更容易获得靠前位置；质量打分较低的分组即使某些单项指标看起来不错，也可能不会排在前面。

### 4. 延迟

延迟会影响用户实际体验。hvoy 会参考测试过程中的响应耗时，并把它作为排序信号之一。

低延迟通常更有优势，但延迟不是唯一指标。一个延迟稍高但稳定、质量好、价格合理的分组，仍然可能排在延迟更低但质量波动较大的分组前面。

### 5. 首次测试通过时间

站点在 hvoy.ai 第一次测试通过的时间也会进入排序参考。

更早通过测试并长期保持稳定的站点，说明它在 hvoy 体系内有更长的可观测历史。新站点不会因为时间短就被排除，但在历史数据不足时，排序会更依赖最近测试结果、认证状态和质量分。

### 6. 认证状态

通过 hvoy 企业/个人认证的站点会获得额外可信度。认证状态会作为排序加权因素之一，也会影响用户在页面上筛选和判断站点。

认证不代表永久靠前。认证站点如果后续出现稳定性、质量或价格异常，排序仍然会根据实际数据调整。

### 7. PartnerPro 流量加权

开通 PartnerPro 的站点会获得额外流量支持，因此在综合排序和曝光分配中会有额外加权。

PartnerPro 不是唯一排序因素，也不会覆盖基础质量要求。站点仍然需要保持较好的稳定度、价格、延迟和通过率，才能持续获得较好的展示效果。

### 8. 用户点击率

用户在排行榜中对某条数据的点击率会被用于判断它对用户是否有吸引力。

如果某个站点和分组在相同曝光条件下更容易被用户点击，系统会认为这条数据对用户更有参考价值，并在排序中给予一定正向信号。

### 9. 用户测试数量和总体通过率

hvoy 会参考用户最近在 hvoy.ai 上对站点发起的测试数量，以及这个站点的总体测试通过率。

近期测试数量较多且通过率较高，通常说明该站点被真实用户频繁验证，并且实际可用性较好。近期测试失败增加、总体通过率下降，都会对排序产生负面影响。

## 页面指标说明

- 站点: 提供该模型或 API 中转服务的站点名称。
- 站点分组: 站点内部用于区分价格、渠道或服务质量的分组。
- 价格: 当前抓取或计算到的该模型输入价格，具体单位以页面展示和站点价格接口为准。
- 价格趋势: 最近一段时间价格相对变化，用于观察涨价、降价或持平。
- 在线率: hvoy 自动探测中请求成功的比例。
- 掺水率: hvoy 根据测试结果识别出的疑似非目标模型、质量异常或结果不一致比例。
- 延迟: hvoy 测试请求的响应耗时。
- 运行状态: 最近连续探测结果的可视化展示，用来观察短期稳定性。

## 排序会动态变化

榜单排序会随着探测结果、价格变化、用户测试、点击行为和站点状态持续更新。某个站点今天靠前，不代表之后固定靠前；某个站点暂时靠后，也可能在稳定性、价格、质量和认证状态改善后上升。

hvoy 排行榜的目标是帮助用户找到当前更值得尝试的站点和分组，而不是给站点做永久排名。
