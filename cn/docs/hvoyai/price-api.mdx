hvoy.ai 默认支持newapi的价格获取, hvoy.ai 默认合作站长允许hvoy.ai 抓取价格进行展示. 如果有站长不允许价格抓取, 请联系我们关闭.

我们也支持部分sub2api的价格抓取.

最新的文档请参考  https://hvoy.ai/docs/provider-price-api-markdown

对于一些不支持格式的站点,  请沿用这个规范, 向hvoy.ai开放接口

请准备一个接口, 返回最少以下数据.
