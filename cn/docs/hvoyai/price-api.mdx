合作站点默认允许 hvoy 抓取站点的模型价格进行展示。如果有站长不允许价格抓取，请联系我们关闭。

hvoy 已支持 newapi 及部分 sub2api 系统站点的价格抓取。对于暂时不支持价格抓取的站点，请您按照以下规范开发一个价格接口，并将 URL 通过站长后台提交工单给我们，我们收到后会帮您处理。

开发文档规范：https://www.hvoyai.com/docs/provider-price-api

自测链接：https://www.hvoyai.com/docs/provider-price-api-fetch

请准备一个接口，至少返回以下数据：
