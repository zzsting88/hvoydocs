hvoy 目前不提供对外的 API 测试调用。

但您可以使用下面这个快速测试方法。

例如：

https://www.hvoyai.com/?api=baidu.com&model=opus48&note=cc%E5%88%86%E7%BB%84&modelid=claude-opus-4-6



- `api` 参数决定默认填写哪个 URL。
- `model=opus46/sonnet46/gemini31/opus47/opus48/gpt54`，也可以填写 `opus4.6/sonnet4.6/gemini3.1/opus4.7` 等类似格式。
- `modelid=claude-sonnet-4-6`，一般不需要填写这一项。但如果有些中转站里的模型名是 `[官]claude-sonnet-4-6`，就需要填写这一项。
- `note` 为备注，可以填写分组名称，也可以不填。
