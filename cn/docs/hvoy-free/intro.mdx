## 什么是 HvoyFree

每家 AI 实验室都提供免费额度, 单独拿一家的免费额度只能当玩具

但如果把十几家叠在一起，就能拼出大约 **每月 13 亿 Token** 的token.

HvoyFree 把这些全部收集到一个地方, 把你客户端指向聚合的地址, 你可以轻松的使用这些免费API, 够日常简单使用.

这些API都只在本地存储,没有任何安全隐患.

## 使用示例

如果你想要使用这些apikey

只需将 `base_url` http://localhost:4321/v1 即可.

<CodeGroup>
```python Python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:4321/v1",
    api_key="hvoyfree-key",
)

resp = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

```bash curl
curl http://localhost:4321/v1/chat/completions \
  -H "Authorization: Bearer hvoyfree-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

```python 流式输出
stream = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "写一首关于代码的诗"}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```
</CodeGroup>

`model` 设为 `"auto"` 时路由器自动选择最优模型，也可以指定具体模型如 `"gemini-2.5-flash"`。

每个响应会携带 `X-Routed-Via` Header 告诉你实际是哪个提供商/模型处理了请求。
