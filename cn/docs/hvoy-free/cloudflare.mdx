## 怎么领取
Cloudflare 是这些站点里最大方的一个，每个月大概可以拿到 20M Kimi K2.6、20M Kimi K2.5，还有一些其他额度，不愧是互联网大善人。

第一步，打开：https://developers.cloudflare.com/workers-ai/

第二步，登录（可能需要注册）。
![cf1](/assets/images/cf1.jpg)

第三步，到 Dashboard 页之后，点击 AI。
![cf1](/assets/images/cf2.jpg)

第四步，先选择 Workers，然后选择 REST API。
![cf1](/assets/images/cf3.jpg)

![cf1](/assets/images/cf4.jpg)

创建 API Token。
![cf1](/assets/images/cf5.jpg)


把 API Token 和 AccountId 都复制出来，填到 hvoyFree 里。
![cf1](/assets/images/cf6.jpg)

![cf1](/assets/images/cf7.jpg)
