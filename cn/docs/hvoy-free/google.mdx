## 怎么领取
首先，需要有一个可以请求到 Google 的 IP。

其次，打开网站：https://ai.google.dev/

![google ai](/assets/images/google1.jpg)

然后添加免费的 API Key。
![google ai](/assets/images/google2.jpg)

可能需要创建一个 Project。
![google ai](/assets/images/google3.jpg)

创建完 Project 之后，创建 API Key。
![google ai](/assets/images/google4.jpg)


创建完 API Key 之后，每个月就有一定的免费额度。
![google ai](/assets/images/google4.jpg)
